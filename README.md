📚 Book Review Platform - Frontend
A responsive book review platform built with React, Vite, and Tailwind CSS.

🚀 Features
User authentication (signup/login)

Add, edit, delete books

Write and manage reviews (1-5 star rating)

Search & filter books by title, author, genre

Pagination & sorting

User profile page

🛠️ Tech Stack
React 18 + Vite

React Router v6

Axios

Tailwind CSS

Context API

⚙️ Setup
bash
# Install dependencies
npm install

# Create .env file
VITE_API_URL=http://localhost:5000/api

# Run development server
npm run dev

# Build for production
npm run build
